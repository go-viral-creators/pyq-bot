Accessibility Service Disclaimer

Required disclosure for Google Play's AccessibilityService API policy.

Last updated: October 10, 2026

In plain words

AuraMic AI uses Android's Accessibility Service for one purpose only: after you record a voice note with the floating mic, it chooses the chat you were in and taps the Send button inside WhatsApp or WhatsApp Business so the note is delivered without extra taps. It also looks up where WhatsApp's own voice button is on the screen, so the AuraMic microphone can sit exactly on top of it. It does not read, collect, store or share your messages, contacts or any personal data.

1. Why the Accessibility API is needed

Chat apps offer no public API for sending a file into the conversation you have open. Android's share sheet opens WhatsApp's chat picker and then requires you to choose a chat and tap Send. AuraMic automates exactly those two on-screen taps. There is no other way to deliver this core feature, and the feature is optional: turn off Auto-send in Settings and AuraMic simply opens the share screen for you to finish manually.

2. What the service can see and do

  • Scope: limited by its configuration to com.whatsapp and com.whatsapp.w4b. Windows of other apps are never inspected.
  • When: while WhatsApp is open it checks whether a chat is open and where the voice button is (position only), and after you release the mic button it acts for a few seconds (at most 25 seconds).
  • What it reads: the title of the open chat, and the labels of buttons / chat names on the share screen, solely to find the right row and the Send button. Message text is not read. If auto-send fails, a shortened structure dump (names cut to a few characters) is kept in memory and copied only when you tap “Copy diagnostics”.
  • What it does: scrolls the picker list, types the chat name into WhatsApp's own search box when needed, and clicks the matching chat and the Send button. It never taps Send unless it has itself selected the chat, so a half-typed message in another conversation is never sent by accident.
  • What it never does: it does not log keystrokes, capture screen content, monitor passwords or payments, change settings, install software, or send any information off your device.

3. Consent and control

Before the system settings screen is opened, the app shows an in-app disclosure that you must accept. The service is off until you enable it in Settings → Accessibility, and you can disable it there at any time. Disabling it only disables auto-send.

4. Not an accessibility tool

AuraMic AI is not designed to help people with disabilities and does not declare itself an accessibility tool. We use the API solely for the automation described above.

5. Restricted settings (sideloaded installs)

On Android 13 and later, apps installed outside the Play Store may find the switch greyed out. Open Settings → Apps → AuraMic → ⋮ → Allow restricted settings, then enable the service.
